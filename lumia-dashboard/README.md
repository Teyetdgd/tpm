# Lumia Dashboard

A Ring 3 LumiaSDK showcase for windows, buttons, progress bars, the monotonic
clock, repeating timers, notifications, clipboard access, and central GUI
events. Press a key while the window is focused to see its event counter move.

```bash
make LUMIA_SDK=/path/to/Lumia-OS/sdk/toolchain
```

Run `build/lumia-dashboard.lxe` with the LumiaOS `run` command.
