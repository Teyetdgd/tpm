# Lumia Control Center

Lumia Control Center is a substantial Ring 3 SDK application combining a
multi-panel dashboard, events, timers, sliders, buttons, clipboard exchange,
VFS persistence, and notifications.

Its deterministic 2 MiB diagnostics dataset is part of the application and
makes the LXE useful for validating Mikasa's progress, throughput, and ETA.

Build it from the parent directory with `make lumia-control-center`.
